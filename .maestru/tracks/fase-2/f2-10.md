# F2-10: Coleção de templates de componentes com acesso restrito a admin

## Descrição

Criar uma coleção/catálogo de templates de componentes gerida apenas por utilizadores com role ADMIN (ver `E5-10`). Inclui CRUD de templates (criar, editar, remover, publicar) e bloqueio de acesso de escrita para utilizadores comuns, que apenas consomem o catálogo via `GET /components` (`E2-06`).

**Referência:** `Docs/arquitetura_simulador_circuitos.md` §11

## Nota (pós-conclusão)

A coleção `templates` (MongoDB) passou a ser a única fonte da verdade do catálogo do backend: `app/circuit/catalog.py::load_catalog()` lê-a diretamente (sem cache), e o ficheiro estático `apps/api/app/circuit/data/components.json` foi removido. O catálogo estático do frontend (`packages/circuit-schema/catalog/components.json`), importado em build-time por `apps/web`, manteve-se intacto — migrá-lo para a API é um refactor maior, fora do âmbito desta alteração.
